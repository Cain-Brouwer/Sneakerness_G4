# Sneakerness G4

Welkom bij **Sneakerness G4** — een website met informatie over een sneakerevent.

## Over het project
Deze website is bedoeld voor bezoekers die alles willen weten over het event:
- wat Sneakerness is
- wanneer en waar het plaatsvindt
- welke activiteiten er zijn
- praktische informatie voor bezoekers

## Inhoud van de website
Op de website vind je onder andere:
- eventinformatie en programma
- details over sneakers, stands en exposanten
- locatie- en tijdsinformatie
- updates en belangrijke mededelingen

## Doel
Het doel van deze website is om alle informatie rond het sneakerevent overzichtelijk en toegankelijk op één plek te tonen.
